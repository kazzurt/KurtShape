## Changes

- The bridge now flushes an early header refusal, half-closes its write side,
  then drains unread buffered input for at most 250 ms / `REQUEST_SIZE_LIMIT + 1`
  bytes. This prevents an ordinary unread request body from resetting the
  Windows connection before the client receives its 400/403/413 response.
  Rejected requests still never reach registration or dispatch. Valid requests
  and body-consumed refusals do not drain. The operation contract documents the
  cleanup limits and the remaining reset possibility beyond either limit.
- Branding retains Qt's `[*]` title placeholder. Qt hides it while unmodified
  and manages the modified marker itself; omitting it caused native
  `QWidget::setWindowModified` warnings to pollute Messages severity counts.
- Added bounded-cleanup, refusal-delivery, registration-isolation and native Qt
  regression tests. The Messages recipe also checks the placeholder and absence
  of the native title warning. Its original severity assertions remain intact.
