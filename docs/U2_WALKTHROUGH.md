# Try the U2 Part Studio

Save and close the older KurtShape window, then launch `KurtShape.cmd`. Running windows retain their loaded code. U2 started from main `d9efdcc`; U1 was not present. The native FCStd remains the editable project.

1. Make two parts. Start a sketch on Top with Shift+S, draw a rectangle with G, Finish, then Shift+E. Choose **New**, enter a depth and Confirm. Use **New part** for a second sketch owner, draw a separated rectangle and Extrude with **New**. Both solids appear once in Parts. Right-click a part to rename, color, hide or show it.
2. Add material to one part. Sketch a rectangle overlapping the first part. Extrude with **Add**, set **Merge scope → Selected parts**, and check only the first part. The preview shows the scoped result; Confirm makes one native history step. The other part keeps its volume. Enter confirms; Shift+Enter confirms and repeats with a new profile.
3. Split a part. Right-click it in Parts and choose **Split**. Choose Plane and set a plane passing through it; a 20 mm wide origin rectangle can use origin `(10,0,0)` and normal `(1,0,0)`. Confirm the preview. Both halves appear as separate editable parts. Selected planar face and Sketch plane are the other split modes. A sketch supplies its plane, not a bounded profile region.
4. Roll back and insert. Drag the slider under history to before Split, or focus the slider and press Up/Down. Later features display Held and current parts change. Insert an overlapping Add extrusion at that position, then move the slider to the end. Later recorded part inputs follow the same logical part identity and rebuild from the inserted result. An incompatible insertion reports its failure.
5. Watch reference health. Select a planar face and press Shift+S to attach a sketch; viewport geometry tools store ownership/geometry/closest-point queries for selected model geometry. Edit an earlier dimension and Rebuild. Supported targets follow the evaluated query. Missing or tied targets show a red `!` in history with a diagnostic tooltip; inspection includes each input's health. Repair the input before exporting. Retained old geometry is never reported as current successful geometry.

**Transform / copy**, part patterns, Mirror and Delete are in the Parts context menu. Revolve, Sweep, Loft, Boolean, Fillet, Chamfer and Shell use shared typed tools with disposable previews. Drag Loft sections into the intended order. Sweep can use a sketch curve or a selected model edge stored as a selector. For fillet/chamfer/shell, select edges/faces in the viewport before opening the tool. Export includes all current parts once, including hidden parts; it excludes upstream generations and auxiliary tools. Save as FCStd to retain history, selectors, part identity and rollback.

For assistant-created references, `resolve_selector` previews the matched geometry without mutation. The [operation contract](OPERATION_CONTRACT.md) contains exact schemas. More precise selectors can use created-by start/end/side caps, geometry, adjacency, parallel direction and set operations rather than a point preference.

## Limits and verification

The implementation uses native Bodies and native Part/PartDesign compositions. It is pinned to FreeCAD 1.1.4/OCCT 7.8.1; creator-history decoding fails closed on unknown runtime/map formats. Split accepts planes and planar faces. One logical part must remain one valid solid; empty or disconnected results reject. Extrude/Revolve/Sweep/Loft reevaluate automatic scopes on managed Rebuild. Changed automatic pattern scopes and unsupported downstream native-consumer migrations require reapplying the affected feature. Caps have supported native geometric cases and explicit unsupported cases; [parity](ATLAS_PARITY.md) records these boundaries.

Reproduce with `run-checks.ps1` and `tools/validate-u2-part-model-gui.ps1`. Small JSON reports are committed; native FCStd fixtures and rendered PNGs are reproducible local validation material. [Carrier decision](PART_MODEL_DECISION.md) records the comparison, persistence probes and native naming findings. Full historical Dodec conversion remains 0/2 and belongs to U5. This increment makes no Onshape API calls.

Final checks passed: 141 native tests, 4 bridge tests, 22 keyboard tests and 99 U2 GUI checks. The final native GUI scene and failure displays were visually inspected; source hashes match the files used by both offline and GUI acceptance.
