## Hands-on checklist for Kurt

Restart KurtShape on this code first (from the `ksasm` worktree, or after merging `claude/assembly-ux`); a running app keeps its old code.

1. Part studio: click two faces → both stay selected; click one again → it drops; click background or press Space → clear. (Settings → Selection → "Click adds to selection" switches it off.)
2. Watch the bottom-right readout: one face (area, normal), two parallel faces (parallel distance), two vertices (distance + ΔX ΔY ΔZ).
3. Assembly: click faces on two instances → both rows light up in both lists and the list centres the last one.
4. Right-click an instance → **New folder**, type a name, Enter; select several rows → **Move to folder ▸**; right-click the folder → Rename / Remove; type in the filter box.
5. Right-click an instance → **Open part** (or double-click) → the part opens in its own tab; repeat → the same tab comes forward.
6. Insert a STEP part: its rows show the cube-with-arrow icon; Open part imports it; **Show source file** prints the path.
7. In the part's tab add a feature and save → status "used in <assembly>"; back in the assembly press **F5** (or the Refresh button) → "n parts changed on disk", rows say "· outdated" in amber; F5 again → "Updated n parts".
8. Leave a part edit unsaved and press F5 in the assembly → "unsaved in another tab" instead of outdated.
9. Insert a part you built and saved in the GUI with an edited sketch: it used to be refused (`unsafe_assembly_source`) and now inserts.
10. Look at "Open questions" in rows 1, 4 and 7 below; anything odd goes back into this file.
