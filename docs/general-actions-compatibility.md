# General shortcut actions

`GeneralActions(panel).callbacks()` supplies `general.copy`, `general.paste`, `general.feedback`, `general.tabs`, `general.tab_manager`, and `general.select_other` for `ShortcutRouter`. Keep the instance on the panel. It registers a native document observer; panel destruction calls `close()`, which can also be called explicitly during shutdown. It uses the panel's `core`, document selection, current native Sketcher edit, status feedback, and refresh methods. No parallel document is created for clipboard work.

## Native copy and paste

Outside sketch edit, Ctrl+C copies a reference and fingerprint for one native Sketcher sketch, Pad, or Pocket in the current Body. Ctrl+V uses `doc.copyObject(source, False)` and inserts that native feature into the same Body, retaining actual support/profile dependencies, named dimensions, constraints, and feature parameters. It refuses copied Bodies, frozen solids, unknown feature types, cross-document dependencies, changed/deleted sources, and unfinished modeling tasks. Each paste checks the current revision, creates a native undo transaction, recomputes, checks validity, and aborts failed changes. Repeated paste is supported.

Pasting Pad/Pocket initially repeats an overlapping operation and can leave volume unchanged. Its numeric parameters are independent, while its original sketch profile remains shared. Pasting a sketch creates independent native sketch geometry and constraints; its attachment and external references remain shared. Sketch paste preserves the existing solid Tip. These are explicit local equivalents to feature copy, not a claim that arbitrary Onshape feature graphs have been translated.

Inside a sketch, Ctrl+C/Ctrl+V invoke the installed `Sketcher_CopyClipboard`/`Sketcher_Paste` commands for selected geometry and related constraints. Paste uses native placement in the viewport. The wrapper accepts only unchanged native clipboard data produced by its own geometry-copy command. Unrecognized clipboard contents produce clear feedback. Native Sketcher exposes this clipboard behavior in the [official workbench documentation](https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Sketcher_Workbench.md). Nonrecursive native object copying retains dependency links, consistent with the [FreeCAD document API](https://freecad.github.io/SourceDoc/d8/d3e/classApp_1_1Document.html).

## Select other

The single backquote key opens native entity choices under the pointer. `view.getObjectsInfo((physical_x, physical_y))` supplies ordered ray hits, including faces behind opaque objects. The wrapper converts Qt global/logical pointer coordinates to physical bottom-left viewport coordinates using the active native view size and device pixel ratio. It does not substitute a guessed face or a different object.

Menu hover highlights the actual native hit; choosing an item adds its exact native document/object/subelement to the selection. Existing selections remain, and cancellation changes none of them. The camera, active document, and sketch edit are preserved. A changed revision or editing context rejects stale selection. Native selection gates remain authoritative. The installed FreeCAD 1.1.4 uses `setPreselection(obj, subName, x, y, z)` and `clearPreselection()`; the older document/name preselection call form is not accepted in this runtime.

Eight checks in `validation/general-actions-select-other-result.json` passed using real opaque front/rear solids at 150% DPI, including choosing and highlighting an occluded rear face, selection preservation, exact context/camera/revision preservation, cancellation, stale revision rejection, and pointer boundaries. The raw native API probe is in `validation/general-actions-select-other-probe.json`. Reproduce with `tools/general-actions-select-other-validation.FCMacro` in the same isolated hidden validation setup below. A first hidden-menu inspection approach using platform `activePopupWidget` did not work with `WA_DontShowOnScreen`; the test now inspects the native Qt chooser under its owner and uses a bounded menu watchdog.

## Document switching and reports

Ctrl+Space switches to the most recently active managed native document. Alt+T opens a chooser for all open managed part studios. Current sketch leases, native edit sessions/task dialogs, custom feature dialogs, and sketch-plane selection must be finished or canceled before switching. The native guard checks both `getInEdit()` and the task dialog, including non-sketch Pad edits. Canceling the native task restores document switching. Selection, view state, and native feature graph remain in their own document.

Ctrl+U asks for a problem description and saves JSON under `validation/user-reports`. Reports include the runtime version, current document revision/build status, selection, and visible status message. They do not read assistant-session files, credentials, or clipboard contents; nothing is sent externally. `zoom_to_selection()` is available as an optional toolbar/menu callback using installed `Std_ViewFitSelection`. The official Onshape table assigns no default shortcut to that local action, so the registry remains unchanged.

Local Ctrl+S/N/O use the application's staged/recovery file handlers even when a line or spin input has focus. Text copy/paste and undo retain their native field behavior. Modal dialogs own their shortcuts. Ctrl+Shift+S could be a future local Save As extension, provided it retains the different official Feature Studio Commit All meaning in that context.

## Evidence and reproduction

`validation/general-actions-feature-copy-probe.json` verifies native shallow copies for all three declared feature types. All 25 checks in `tools/general-actions-validation.FCMacro` pass for independently editable pasted parameters, native undo/redo, consecutive paste, constrained attachment preservation, stale-source rejection, cross-document rejection, actual selected-geometry clipboard and viewport placement, managed document switching, persistence, task/lease protection, and local report contents. Native Pad task regression opens the actual editor, verifies recent switching and the chooser are rejected, clicks its real Cancel button, then verifies switching resumes. The harness identifies Sketcher edits by native type so the Pad guard cannot pass by misclassifying the Pad as a sketch. The hidden session preserves and restores the user's original clipboard and does not start the KurtShape UI or its assistant endpoint. Results are in `validation/general-actions-gui-result.json`; the native test document is `validation/general-actions-native-copy.FCStd`.

Run the macro using the portable `freecad.exe` with separate `-u` and `-s` config files under `runtime/general-actions-probe`, `KURTSHAPE_ROOT` set to this project, `TEMP/TMP` under `runtime/temporary`, and `-WindowStyle Hidden`. Do not reuse the interactive application's session/config for validation. Physical user walkthrough acceptance remains separate from these automated checks.
